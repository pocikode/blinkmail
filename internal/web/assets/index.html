Blinkmail

Disposable inbox

Addresses are public. Anyone who knows an address can read every message in it. Do not use a Blinkmail address for passwords, banking, or anything private. Removing an address hides it from this browser only — it does not delete the messages.

Letters, digits, dot, underscore, hyphen and plus are allowed, up to 64 characters. An address that already exists will be added to your list, including its existing messages, because addresses are public.
